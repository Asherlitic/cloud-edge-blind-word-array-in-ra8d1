=================================================
       GIT 完整操作指南 (Asher 专属版)
=================================================
项目：thermal_video_gui (热红外视频处理)
角色：Asher (Zhou Lehua)
-------------------------------------------------

一、 基础“存档” (每天的核心动作)
-------------------------------------------------
1. 查看状态: git status
2. 添加暂存: git add .
3. 正式提交: git commit -m "说明你的改动"
   (建议实现一个功能就提交一次，如：提取温度矩阵成功)

二、 分支管理 (标准流程 SOP)
-------------------------------------------------
场景：当你准备在 thermal_image_processor.py 中尝试新算法时：

1. 开辟实验室 (创建并进入分支):
   git checkout -b feature-thermal-algo

2. 疯狂试错 (在分支里改代码、commit):
   git add .
   git commit -m "分支存档：尝试新的伪彩色映射"

3. 回归主线 (功能写好后，先回到 master):
   git checkout master

4. 正式融入 (将实验室成果吸纳进主代码):
   git merge feature-thermal-algo

5. 拆除实验室 (删除已合并的临时分支):
   git branch -d feature-thermal-algo

6.找所有分支
   git branch

三、 撤销与找回 (后悔药)
-------------------------------------------------
1. 救命药: git checkout -- <文件名> 
   (放弃当前没存的修改，恢复到上次存档)
2. 翻旧账: git log --oneline
   (查看所有历史存档 ID)
3. 时光机: git reset --hard <版本ID>
   (彻底回到过去某一天)

四、 避坑指南
-------------------------------------------------
1. 必须建立 .gitignore 文件，写入以下内容防止混乱：
   __pycache__/
   *.mp4
   .vscode/
   build/

2. 遇到冲突 (Conflict) 别慌：
   VS Code 会标红冲突行，手动选择“保留双方”或“保留分支更改”即可。

3. 团队协作 (等):
   在 push 自己的代码前，记得先 git pull 同步队友进展。
